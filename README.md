# AutoCut EDM Expert - Hệ Thống Tra Cứu Chế Độ Cắt Dây Molypden CNC Động Cơ Servo

Ứng dụng web chuyên nghiệp phục vụ tra cứu, phân tích chế độ điện gia công và tính toán lượng bù dao (Offset / Remain) cho máy cắt dây Molypden điều khiển bằng hệ thống AutoCut Servo.

## 🚀 Tính năng nổi bật
* **2 Nhóm vật liệu chính:** Thép hợp kim dẻo mềm SCM420 (HB < 200) & Thép tôi cải thiện SCM440 (28 - 32 HRC).
* **Quy trình cắt đa dạng:** Hỗ trợ từ cắt 1 lần (1 Pass lấy đứt) đến 6 lần (6 Pass bóng gương).
* **5 Mục tiêu chất lượng & Chiến lược gia công:** Siêu năng suất, Năng suất cao, Tiêu chuẩn, Bề mặt mịn, Bề mặt siêu mịn.
* **Dải chiều dày phôi rộng:** Nhập từ $5\text{ mm}$ đến $500\text{ mm}$ (bước nhảy $5\text{ mm}$).
* **Khung thử nghiệm & Bảng so sánh đối đầu:** Phân tích thông số tùy biến và so sánh trực tiếp với tiêu chuẩn của Hãng.
* **Cẩm nang toàn tập Kiến thức chuyên sâu EDM:** Giải thích cặn kẽ bản chất vật lý của $ti, Po, IP, \text{Voltage}, VF, \text{Wire}, \text{Offset}$.
* **In phiếu công nghệ chuyên nghiệp:** Tự động định dạng khổ ngang A4 Landscape.

## 🛠️ Công nghệ sử dụng
* HTML5, CSS3 (Dark mode công nghiệp, Responsive layout).
* Pure JavaScript (Không phụ thuộc thư viện ngoài, tải tức thì).
